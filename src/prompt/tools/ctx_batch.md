Example: `ctx_batch({commands:["git log --oneline -5"],queries:["recent changes"]})`. Required: commands, queries.
Runs shell commands in order and searches their combined output. Returns each command's exit or stop status, a batch summary and selected sections; long status lists have a source pointer. Normal nonzero exits continue: judge each command's meaning, including no matches. Mixed or incomplete results remain unknown in recovery. Use it for several facts when full text is unnecessary. Follow source pointers for omitted output; a final exit 0 does not prove earlier commands succeeded.
