Example: `ctx_search({queries:["auth middleware"]})`. Required: queries.
Searches indexed content, earlier sandbox output and memory files. Pass several queries in one call. Defaults to the current worktree; set scope to project for all worktrees or session for this session. Current-session results rank first, then relevance. Set sort to timeline with after for oldest first; offset pages relevance results. Set source to decision for user answers. A named source with no query matches explicitly returns chunks by position as a fallback, not matching evidence. Unknown sources return no hits. Follow paging pointers for omitted text.
