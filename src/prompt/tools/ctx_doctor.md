Example: `ctx_doctor({})`. Required: none.
Checks version, Node/SQLite, host config, hooks, MCP, project, database, index and timing. This tool can heal database files, write reports and index large reports. For strictly read-only checks use the native `context-mode doctor` CLI and pass your actual host to `--agents`. List failed rows and fixes; run only actions already authorized for their owner. Pennix Lifecycle owns installation, updates and removal. Reports contain paths and environment details: show the report and obtain approval before sending a GitHub issue.
